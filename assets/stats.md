# 互动统计（可选）

> 不需要计数可以直接删除本文件。
> 需要时按下方格式自定义维度，`SKILL.md` §2 会在每次生图后静默更新。

```markdown
# starai stats
scene_count: 0       # 场景数：每次新场景 +1
image_count: 0       # 配图数：每生成一张图 +1
```

## 自定义维度（按需添加）

| 维度 | 说明 | 示例 |
|---|---|---|
| `scene_count` | 场景数 | 每次开启新场景 +1 |
| `image_count` | 配图数 | 每生成一张图 +1 |
| `gift_count` | 送礼数 | 角色送用户礼物时 +1 |

更新规则：每次互动后按自定义维度 +1 并落盘，只在后台更新，不出现在正文。
